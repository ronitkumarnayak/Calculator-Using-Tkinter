# Calculator-Using-Tkinter
Simple GUI calculator built using python and Tkinter
In this project i learnt how to create a graphical user interface,handle button events,
and perform basic arithmetic operations.

#Features
~It support basic arithmetic operations:
>Addition(+)
>Subtraction(-)
>Multiplication(*)
>Division(/)
~Numeric keypad(0-9)
~Clear button to reset input
~Real-time display using an Entry Widget

#How it works
1.The calculator window is created using Tk()
2.An Entry widget is used as the display screen.
3.Buttons (0–9) allow users to input numbers.
4.Operator buttons store the first number and selected operation.
5.When the equals (=) button is pressed:
>The second number is read.
>The stored operation is performed.
>The result is displayed.
